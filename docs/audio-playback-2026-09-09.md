# 텍스트 클릭 재생·파형과 레이아웃 수정

확정 전사 텍스트를 누르면 해당 발언만 재생한다. 기본 audio controls를 제거하고, 한 발언만 활성화하는 재생 상태를 사용한다. 일시정지·종료 시 200ms 동안 파형을 접은 뒤 DOM에서 제거한다. 다시 클릭하면 일시정지는 이어듣기, 종료된 발언은 처음부터 재생한다. 파형의 탐색 슬라이더는 키보드로도 조작할 수 있다. 모션 감소 설정은 애니메이션을 생략한다.

실제 WAV를 AudioContext로 디코딩해 56개 RMS 막대를 만들고 진행률을 표시한다. 텍스트 선택과 5px 이상 드래그는 재생을 유발하지 않는다. 로딩 중 클릭은 요청을 취소한다. 다른 발언 선택, URL/전사 버전 변경, 행 가상화로 인한 unmount, 페이지 이동, 권한 거부 후 화면 해제 시 네트워크·오디오·Blob·AudioContext 자원을 정리한다. 일부 브라우저의 자동재생 제한 시 문장을 다시 눌러 이어서 재생하도록 안내한다.

## API

GET /api/meetings/:id/segments/:segment_id/audio 에 선택적 transcript_version 추가. 같은 화자의 유효한 암호화 원음만 조회한다. PCM 샘플 단위로 앞뒤 경계를 절단하고 시간 간격은 0으로 채워 보존한다. 중복 조각의 같은 샘플은 반복 삽입하지 않는다. 길이는 최대 5분으로 제한한다. X-Audio-Missing-Ms 헤더로 저장 누락 시간을 전달하고, 원음이 아예 없으면 AUDIO_UNAVAILABLE로 안내한다. 기존 워크스페이스 멤버십·삭제 상태를 변환 전후 검사한다. 응답은 private,no-store이고 원음 마운트는 읽기 전용이다.

참가자 영역은 남은 높이 안에서 독립 스크롤하며 grid의 행 최소 높이를 0으로 제한한다. 요약 탭 내부의 이중 여백을 정리했다.

## 검증

- WAV 조립 단위 테스트: 양쪽 경계, 중복 조각, 무음 간격, 헤더 길이.
- PostgreSQL/API 테스트: 다른 화자 제외, 정확한 발언 길이, 미로그인 401, 잘못된 버전, 만료 404.
- 브라우저: 기존 8개 시나리오 및 파형 재생/중지/전환/종료, 텍스트 선택/키보드/취소/실패 안내. 360px 모바일 가로 넘침 및 1100x600 참가자 패널 실제 스크롤 확인.
- 운영 원음 읽기 전용 스모크: 실제 1,720ms 발언 → WAV 55,084바이트, 1,720ms, 누락 0ms. 실제 음성을 청취해 내용을 판정한 시험은 아니다.

## 배포

API 서비스만 교체한다. MEETING_API_IMAGE로 봇·작업자 이미지와 별도 고정하며, 봇/작업자의 컨테이너 ID 및 StartedAt 전후 일치를 확인한다. DB 마이그레이션과 회의 데이터 수정은 없다. 원음은 /data/audio에 읽기 전용 마운트한다. API 재시작 중 웹 연결은 재접속할 수 있지만 음성 수집 프로세스는 유지한다.

최종 검증: Playwright 10개 모두 통과, API 통합 6개 및 WAV 조립 단위 테스트 통과. 배포 이미지 juncoy-meeting:0.1.0-waveform3 (cb9ddf5e6b2f). 봇·작업자의 ID와 시작 시각이 배포 전후 동일했다. 이전 API 이미지 summaryonly2로 MEETING_API_IMAGE만 변경하면 롤백할 수 있다.
