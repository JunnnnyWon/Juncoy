## 부하 측정

4시간 동안의 발언에 해당하는 **5,760개 final과 partial**을 가속 재생했습니다. 실제 4시간 동안 음성을 수신한 시험은 아닙니다.

| -------------------------- | ----------------- |

| 가속 재생 실행 시간        | 139.507초         |
| 최종 cursor 일치           | 12개 모두 일치    |
| 순서 오류                  | 0                 |
| 커밋→SSE 수신 p95          | 160ms             |

| 시험 중 유료 provider 연결 | 0 (명시적 mock)   |

이 수치는 SSE 수신 지연이며 실제 발화 종료→브라우저 표시 지연을 대신하지 않습니다. 브라우저 12개 시험은 별도로 수행했습니다.

## 공급사 동시 연결 정책 변경

실제 계정으로 12개 WebSocket을 시도했을 때 10개가 연결되고 11·12번째는 429로 거절되었습니다. 이것만으로 조직의 계약상 총 한도를 단정하지 않습니다. 확인 당시 사용 가능한 연결 수에 맞춰 10개로 설정했고, 사용자가 요청한 FIFO·빠른 슬롯 반환·장기 연결 교대를 구현했습니다. 대기 중 보존된 원음은 파일 큐에서 복구합니다.

## 아직 실제로 검증하지 않은 항목

- 2인 및 12개 실제 계정의 DAVE 음성 수신·SSRC 매핑·겹친 발화·재협상.
- 실제 회의에서 철회/일시정지 이후 저장·전송 0바이트 계측.
- 실제 디스크·DB·음성 네트워크 장애 및 모든 프로세스 재시작.
- 실제 사용자 탈퇴·역할/채널 권한 제거.
- 실제 12인 60분 회의, 발화 종료→웹 final p95 5초, 1시간 회의 요약 p95 120초.
- 팀 용어 정답셋 인식률 90%, 한국어 CER 12% 기준. 합성 음성 파일 한 건으로 이 수치를 주장하지 않습니다.

따라서 원본 명세의 모든 인수 시험을 완료하거나 음성 품질 목표를 달성했다고 선언하지 않습니다. 위 항목은 팀이 참여하는 테스트가 필요한 `BLOCKED_EXTERNAL`입니다. 기능이 없는 UI mock 상태와는 구분됩니다.

## 실제 인수 실행 순서

1. 관리자 포함 2명이 `tesitng`에 들어가 역할·동의를 확인하고 `/회의 시작`을 실행합니다.
2. 각자 다른 검증 문장을 읽습니다. 같은 닉네임, 재입장, 겹친 발언을 반복합니다.
3. 중간에 한 사람이 철회하고 다시 동의합니다. 일시정지·재개도 수행합니다.
4. 웹 새로고침·네트워크 끊김·권한 회수를 확인하고 최종 전사를 서버 canonical과 비교합니다.
5. 종료 후 요약·근거·MD/TXT를 확인합니다. `verify:dave`로 protocol·원음 사용자 수·계정별 검증 문장을 확인합니다.
6. 12명으로 확대해 10개 슬롯과 FIFO 교대·파일 복구를 포함한 60분 회의를 수행합니다.

CER은 평가셋을 고정하고 Unicode NFC, 공백·구두점 제외, 영문 소문자화를 양쪽에 동일하게 적용한 문자 편집거리/정답 문자 수로 계산합니다. 숫자 읽기와 ITN 표기 정책도 평가셋 작성 때 고정합니다. 결과와 장치·버전·조건을 함께 기록합니다.
