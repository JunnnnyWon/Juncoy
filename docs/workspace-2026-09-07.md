# 23팀 공용 워크스페이스 적용 보고서

23팀 서버 1545264536158740590의 현재 멤버는 역할·기록 채널 권한·회의 참석과 관계없이 동일한 기록을 열람한다. 오프라인 여부는 접근 조건이 아니다. 관리 명령의 권한은 유지한다.

## 구현

- OAuth 완료 전, /api/me, 목록 및 모든 회의 데이터 API와 SSE에 멤버십 검사 적용. 비구성원은 WORKSPACE_FORBIDDEN(403), 미로그인은 401, 공급사 확인 장애는 503.
- 신원 및 서버 멤버 API만 사용. 세션+워크스페이스+권한 epoch 기준 캐시 10초, 동시 요청 공유, 429 cooldown 유지.
- 웹은 10초 간격으로 접근을 확인하고 실패 시 회의 컴포넌트를 제거한다. 요청 제한시간 8초. SSE의 접근 거부는 access.revoked로 전달한다.
- 005_workspace.sql의 workspace_meetings 연결로 이전 실제 기록 3건 공유. 원본 서버, ID, 전사 버전, 비용과 삭제 이력 유지. 23팀에는 mock 2건 미포함.
- 신규 회의는 생성 트랜잭션에서 연결한다. 개별 링크도 연결과 삭제 상태 확인 후 허용한다.
- 워크스페이스 명칭 및 공유·로그인·다운로드 문구 갱신. #봇 게시 고정과 동의 절차 해제는 유지.
- 마이그레이션 로더는 번호로 시작하는 SQL 파일만 읽으며 Docker 빌드에서 macOS AppleDouble 파일을 제외한다.

## 검증

- Vitest 85개 통과. 마이그레이션 로더 수정 후 권한/API 9개 재검증 통과.
- 기존 Playwright 7개 통과. 신규 공용 문구·멤버십 거부 시 화면 제거 테스트 1개 통과(10.6초). 첫 실행의 텍스트 locator를 실제 DOM 구조에 맞게 수정 후 재검증했다.
- 실제 공급사: 기존 실제 OAuth 세션 1개의 신원 및 현재 23팀 멤버십 확인 통과. 비밀 값은 출력하지 않았다.
- 내장 브라우저 도구 오류로 사용자 로그인 화면 직접 확인은 BLOCKED_EXTERNAL. 자동 브라우저 시험은 mock 환경이며 실제 Discord 음성 검증으로 계산하지 않는다.
- 운영 연결 3건, 원본 서버 ID 유지 확인. 진행 중 실제 회의와 대기 작업 0건 확인 후 배포.
- 백업 20260907T123257Z.dump.enc 인증·복호화, 별도 DB 복원, 001~005 마이그레이션, 현재 삭제 원장 적용 통과.
