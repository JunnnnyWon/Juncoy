# Juncoy 회의록 화면 정리

선택 기능이 없는 워크스페이스 카드, 메뉴 분류 제목, 반복 권한 안내와 상세 기록 안내를 제거했다. Juncoy 브랜드, 회의 목록, 검색·날짜 필터, 실시간 회의 진입, 전사·요약·내보내기 기능을 유지했다. 로그인 소개를 간결하게 정리하고 검색 결과 없음과 실제 빈 목록을 구분했다.

데이터 공유 범위와 기존 통합 기록은 변경하지 않았다. Juncoy에 연결된 회의만 표시하며 기존 멤버십 검사를 유지한다.

검증: TypeScript 검사, 빌드, Playwright 8개 시나리오 통과. 360px 모바일 가로 넘침 없음. 데스크톱 스크린샷 확인 완료.
배포 이미지: juncoy-meeting:0.1.0-cleanui1 (16e8d8f326ae). 이전 이미지 allvoice1로 롤백 가능. DB 변경 없음.
