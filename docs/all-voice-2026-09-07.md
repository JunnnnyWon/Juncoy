# 전체 음성방 감지와 간소화된 설정

- `/회의 설정`의 모든 입력 옵션 제거. 현재 적용 정책을 읽기 전용으로 안내한다.
- detect_all_voice_channels=true: 캐시에 있는 모든 GuildVoice 채널 감지. 채널 생성은 Discord 채널 캐시 갱신 후 다음 감지 주기(최대 30초)에 반영한다. AFK 및 Stage 제외. 시작 직전에도 일반 음성방인지 확인한다.
- 길드 구성원은 역할과 무관하게 시작 가능. 기존 진행자 소유권 및 관리자 정정·삭제 권한은 유지한다. 역할 기반 진행자 우선순위는 빈 설정으로 제거한다.
- 알림·요약은 #봇 고정. 웹 열람은 모든 Juncoy 구성원. 음성방 감지는 안내만 생성하며 녹음은 /회의 시작 후 수행한다. 동시 수집 회의 1개 유지.
- 월예산 입력 옵션만 제거했고 운영 한도 50,000원은 유지한다.
- 자동 테스트 86개, 타입 검사 및 컨테이너 빌드 통과. 새 음성방 실제 수신은 별도 인수 대상.

이미지 juncoy-meeting:0.1.0-allvoice1. 롤백하려면 활성 회의 종료 후 guild_configs.config에서 detect_all_voice_channels를 제거하고 이전 workspace2 이미지로 복귀, 이전 slash 명령을 등록한다.
