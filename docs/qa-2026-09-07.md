## 수정과 재현

- `apps/web/src/App.tsx`: 메뉴 열림 상태에 맞는 이름과 `aria-expanded`, Escape 닫기, 같은 목록 링크 클릭 시 닫기.
- `packages/providers/src/summary-evidence.ts`: 요청별 짧은 근거 참조와 canonical UUID 복원. 발언 원문 및 사용자 ID는 변경하지 않고, 알 수 없는 참조는 거부하며 중복 참조는 제거한다.
- 같은 파일의 `orderedBatches`: 기본 3개 병렬 실행, 결과는 입력 순서 보존. 실패한 요청이 있으면 이미 실행 중인 호출을 모두 기다린 후 작업 재시도로 넘어간다.
- `packages/providers/src/solar.ts`: 근거에 직접 대응하는 결정·업무만 추출하도록 강화하고, 미확인 화자/날짜는 출력 스키마에서 null로 제한한다. Discord 회의의 실제 사용자/시작 날짜는 기존대로 처리한다.
- 공급사 JSON Schema는 `uniqueItems`를 지원하지 않아 실제 400 응답을 확인했다. 해당 키를 제거하고 중복 제거를 로컬에서 수행한다.

재현 스크립트:

```sh
pnpm exec tsx scripts/qa-offline.ts .data/qa/offline-20260907
pnpm exec tsx scripts/qa-offline-verify-summary.ts .data/qa/offline-20260907 새_실험_폴더
pnpm exec tsx scripts/qa-offline-report.ts .data/qa/offline-20260907 실험_폴더
```

첫 명령은 저장된 공급사 job ID를 재사용한다. 요약 실험은 유료 API를 호출하며 기존 실험 폴더를 덮어쓰지 않는다. 업로드 성공 여부가 불분명한 파일 요청을 자동으로 재전송하지 않는다.

모든 처리 시간은 단일 회의의 단일 실행값이다. p95, 실제 Discord 발화 지연, 실제 12인 60분 시험의 통과로 계산하지 않는다.

## 재검증 결과와 운영 반영

| 실험                             | 전체 요약 시간 | 요청 | 입력 토큰 | 출력 토큰 | 내용 검증 |
| -------------------------------- | -------------: | ---: | --------: | --------: | --------- |
| 최초                             |      547.357초 |   16 |   585,581 |    79,139 | FAIL      |
| 짧은 참조·3개 병렬               |      140.740초 |   14 |   317,910 |    33,463 | FAIL      |
| 시간순 참조·항목별 근거 최대 4개 |       78.494초 |   14 |   225,025 |    20,409 | FAIL      |

최종 실험에서도 제안을 채택 결정 및 업무로 잘못 확정했다. 최종 근거 15개가 모두 녹음의 06:14 이내에 몰렸고, 후반부 엔진 선택·AD 역할 논의 등이 최종 요약에서 누락됐다. 전체 661개 발언을 청크에 한 번씩 넣었다는 사실이 최종 요약의 내용 보존을 뜻하지 않는다.

**요약 변경은 로컬 실험 상태로 남기고 운영 배포를 보류했다.** 근거 문장의 의미 판정과 단계별 논의 보존을 개선한 후, 같은 녹음과 별도 정답셋으로 재검증해야 한다. 프롬프트 강화 및 처리 속도 개선만으로 해결됐다고 보지 않는다.

운영에는 모바일 메뉴 변경만 `juncoy-meeting:0.1.0-qa-web1` 이미지로 반영했다. 실제 브라우저에서 기존 OAuth 세션 유지·메뉴 상태·Escape를 재확인했으며 공개 `/healthz`가 real 모드로 정상 응답했다. DB에서 활성 음성 회의가 없는 것을 확인한 뒤 업데이트했다.

자동 검증은 TypeScript와 빌드, Vitest 51개 통과. 최종 참조 정렬·개수 제한 변경 후 관련 unit 30개 재통과. 브라우저 전체 회귀 결과는 `verification-summary.json` 참조. 자동 테스트 통과와 요약 내용 불합격은 별개다.

## 외부 확인이 필요한 항목

Discord 로그인 탭의 재로그인과 최소 2인의 실제 발언이 필요하다. 회의 날짜 및 기존 회의록/정답 전사가 제공되면 날짜·담당자·고유명사 정확도 평가를 추가할 수 있다.
