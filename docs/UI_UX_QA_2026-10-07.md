# Juncoy UI/UX Redesign QA

작성일: 2026-10-07
범위: Graphite + Coral 공통 shell, Art Board, Assistant files/images, mobile layout

## 디자인 기준

- `Graphite + Coral`: graphite work surfaces, warm-white/neutral content surfaces, coral primary actions, mint success, amber warning, red failure.
- 화면별 horizontal reference는 다음 4개를 사용했다.

  - `apps/web/public/generated/app-shell-direction.png`
  - `apps/web/public/generated/art-canvas-direction.png`
  - `apps/web/public/generated/art-inspector-direction.png`
  - `apps/web/public/generated/art-imagebrief-direction.png`

- Banli 결과는 제품 생성 이미지가 아니라 UI direction reference로만 사용했다.
- `imagegen-frontend-web` 기준에 따라 여러 화면을 하나의 collage로 합치지 않고 화면별 이미지를 개별 제작·검수했다.

## 구현 결과

### 공통 shell

- semantic color tokens와 coral action hierarchy를 추가했다.
- active navigation, compact header, focus/disabled/hover contrast를 정리했다.
- 회의 상세의 full-height grid/aside scroll contract는 유지했다.
- 390px viewport에서 navigation과 account 영역이 겹치지 않도록 축약했다.

### Art Board

- compact command bar와 board selector/history control을 적용했다.
- reference card를 자유 배치하고 drag handle, resize handle, snap, multi-select, group 이동을 제공한다.
- role별 usage strength, crop preview/coordinates, rights/hash 상태, Gemini draft/human correction을 inspector에 표시한다.
- autosave는 직렬화하고 local draft는 user/project/board별 IndexedDB에 저장한다.
- mobile은 canvas/inspector 탭으로 전환한다.

### Assistant

- 파일 row와 file inspector를 분리했다.
- 업로드, Parse, index 상태를 각각 badge로 보여준다.
- SHA-256, parser version, cache hit, original verification time, reparse/delete action을 상세 panel에 배치했다.
- generated image는 model, MIME, 크기, hash, review/canonical 상태를 함께 보여준다.
- mobile에서는 작업 패널을 drawer 형태로 열 수 있다.

## 남은 검증

- 실제 OAuth 로그인 세션이 없는 상태이므로 production authenticated browser flow는 완료로 표시하지 않는다.
- 실제 팀 파일의 PDF/scanned PDF quality review는 synthetic fixture QA와 분리한다.
- 실시간 multi-cursor와 visual similarity search는 이번 redesign 범위에 포함하지 않는다.
- Final browser UI smoke: Art Board + Assistant tests passed 2/2 after the file inspector redesign.
