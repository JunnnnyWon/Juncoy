# 음성 수신·요약 후속 검증 보고서

2026-09-07. **구현·자동 검증·운영 배포 완료. 실제 Discord 다중 계정 인수는 별도 보류.**

자동 게시를 유지하되 검증된 사실 원장의 결과만 게시하도록 구현했다. 실패하면 전사는 제공하고 요약은 보류한다. 수동 승인 기능과 구 요약 경로로의 우회는 추가하지 않았다.

## 기존 실패와 개선

- 기존 64분 전사는 661개 발언이며 SHA-256은 `f46e6561b2779d13a1cf6aa7272bdf6f9255c7acffa43bdf45437c0fbd30479b`이다. 원음 정답 검수는 없다.
- 초기 요약은 약 547초였고, 이전 78초 실험도 통합 결과가 첫 구간에 치우치며 제안을 확정했다. 실패 출력과 단계별 해시·근거 범위를 비공개 baseline으로 고정했다.
- 이번 과정에서도 조건부 변경 제안의 잘못된 번복 처리, 지나치게 긴 질문 목록, 유료 평가 병행 시 429를 발견했다. 각각 명시적 변경 허용 쌍+독립 의미 검사, 핵심/보충/비내용 분류, 단일 평가 session lock으로 보강했다.
- 초기 상세 출력의 질문 420개는 최신 회귀 출력에서 0개다. 불명확한 전사 조각을 미결 질문으로 바꾸지 않고 주제의 확인 필요 발언으로 남긴다. 상세 사실과 제외 사유는 원장에 보존한다.
- 5초 대기 버퍼가 찬 상태의 연결 전환을 고쳤고, 앞부분 손실 범위는 원음에서 복구한다. 정상 종료의 마지막 final은 수용하며, 철회·일시정지의 늦은 응답은 gate로 차단한다.

## 음성 정확도

12개 트랙은 서로 다른 이름을 말하는 독립 Yuna TTS 파일이다. 동일한 혼합 회의를 임의로 12명에게 나누지 않았다. 음성은 모두 같은 합성 음색이며, 실제 12명 발성을 대신하지 않는다.

| 점수 | 원문 | 표시 사전 적용 |
| --- | --- | --- |
| CER | 4.04% | 1.01% |
| 용어 인식률 | 66.67% | 100.00% |

`셰이더`가 공급사 원문에서 `쉐이더`로 나오는 차이가 원문 용어 점수에 반영됐다. 사전 적용 결과를 원문 인식률 향상으로 섞어 보고하지 않는다. 실제 64분 녹음의 CER·사람별 정확도는 **UNVERIFIED_NO_HUMAN_REFERENCE**다.

## 범위와 남은 인수

**BLOCKED_EXTERNAL:** 실제 Discord 2인 15분·12인 60분, 재입장/DAVE 재협상/동명이인·닉네임 변경, 사람의 원음 정답 검수. 무인 재생 통과를 이 항목의 통과로 계산하지 않는다. Solar의 별도 의미 검사도 자동 판정이다.

운영 도메인 HTTPS health는 HTTP 200·TLS 검증 정상이다. 이번 실제 브라우저는 로그인 화면으로 확인됐으며, OAuth 재로그인은 브라우저 제어 도구의 `failed to write kernel assets` 오류로 재확인하지 못했다. 인증·권한 코드와 기존 공개 DTO는 유지했으며 별도 자동 브라우저 검증은 통과했다.
