# 23팀 운영 변경

사용자 요청으로 서버 1545264536158740590의 별도 동의 절차를 해제했다.

- `/회의 동의`, `/회의 철회`와 동의 버튼을 제거했다. 공개 명령은 14개다.
- `/회의 시작` 후 일반 음성방(1545264537987452991)의 사람 참가자를 수집한다. 입장만으로 자동 시작하지 않는다.
- 서버 설정 `require_consent=false`는 실제 동의 이력을 위조하지 않고 시작, 수신, 복구 경로의 동의 조건을 생략한다. 회의별 설정 스냅샷을 보존한다.
- 일시정지, 종료, 참가자 부재, fencing, lease, 삭제 검증은 유지한다.
- `bot_channel_id=1546494176127094794`로 안내와 기록 채널을 고정한다. 설정 변경과 outbox 등록 시 모두 적용한다. 명령 응답은 기존처럼 호출자에게만 보인다.
- 시작 권한은 기존 관리자/팀 역할 규칙을 유지한다. 현재 팀 역할 미설정이므로 서버 관리자가 시작할 수 있다. 수집 대상은 역할과 무관한 사람 참가자다.
- 월예산은 기존 운영 한도 50,000원을 유지한다.

검증: 82개 Vitest 테스트 통과, TypeScript 검사 통과, Docker 이미지 빌드 통과. 신규 PostgreSQL 통합 테스트에서 동의 행 없는 수집·복구, 비참가자 차단, 봇 채널 강제, 일시정지·삭제 차단을 검증했다. 실제 Discord 발언 수신 시험은 이번 변경에서 수행하지 않았다.

이미지: `juncoy-meeting:0.1.0-team1`. 이전 이미지: `juncoy-meeting:0.1.0-facts1`.
롤백 시 활성 회의를 먼저 종료하고 길드 설정에서 require_consent와 bot_channel_id 필드를 제거한 다음 이전 이미지로 교체하고 이전 명령 목록을 등록한다. 기존 이미지는 새 설정 필드를 인식하지 못하므로 이미지 단독 롤백은 금지한다.
